# BridgePoint Intelligence

BridgePoint Intelligence is a U.S. property-intelligence platform for contractors, property operators, adjusters, investors and other property-focused teams.

It combines property matching, public/property records, weather exposure, property changes, provenance, evidence, signals and scoring into explainable prioritization — with an explicit distinction between **evidence that deserves attention** and **confirmed physical findings**.

The public dataset intentionally excludes property addresses, customer data and proprietary scoring weights.

Current Connecticut snapshot (August 21, 2026):

- 1,282,833 canonical statewide properties
- 940 verified ranked opportunity rows in the current verified layer
- 456 general-contracting rows
- 342 property-investment rows
- 48 restoration rows
- 48 roofing rows
- 45 public-adjusting rows
- 1 development row

**Important:** a verified opportunity is a prioritization candidate. It is not a confirmed damage determination, insurance claim or completed inspection.
