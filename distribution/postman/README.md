# BridgePoint Postman collection

Import \`BridgePoint_Public_API.postman_collection.json\` into Postman.

The collection includes:
- exact address/property resolution;
- public property detail;
- public building detail;
- parcel cutout;
- live source context;
- BridgePoint Integrity Index publication status;
- platform counters/status;
- package catalog.

The included key is BridgePoint's public/publishable client key, not a privileged service key. Paid/account-gated intelligence is intentionally excluded.

For public Postman API Network distribution, import this collection into the owner's Postman workspace, mark the workspace public and publish the collection.
