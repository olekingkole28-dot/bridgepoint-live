# BridgePoint Databricks Marketplace listing kit

This folder prepares BridgePoint for a provider-side Databricks Marketplace submission.

## Proposed listing
**BridgePoint U.S. Property + Building Intelligence**

**Category:** Geospatial / Real Estate / Insurance / Built Environment

**One-line value:** Resolve U.S. property identities to building, parcel and source-backed spatial context through BridgePoint's national property graph.

## Suggested free sample
A limited, public-safe sample containing:
- canonical property identifier;
- normalized address;
- jurisdiction;
- parcel identifier when available;
- point longitude/latitude;
- public building summary;
- source/provenance labels;
- BII publication state (not unpublished private score data).

## Commercial follow-on
Request-based access can point customers to BridgePoint enterprise delivery rather than exposing the private canonical backend as an unrestricted public share.

## Submission assets
Use \`marketplace-listing.md\` for the listing copy and \`sample_notebook.py\` as the public demonstration notebook.

Publication itself requires the owner's Databricks provider account and Marketplace approval; this repository cannot impersonate that account or accept marketplace terms on the owner's behalf.
