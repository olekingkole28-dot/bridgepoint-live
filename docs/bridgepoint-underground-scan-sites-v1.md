# BridgePoint Caves & Underground Sites v1

An additive, opt-in map layer for real photogrammetry and terrestrial/mobile-LiDAR records of caves and subterranean heritage sites. It is separate from existing Subsurface Wells and underground utility layers.

## User experience

- Adds one **Caves & Sites** button to the existing bpv-dock-actions card in both the website globe and signed-in app.
- When enabled, site icons are visible at map zoom 0–24; the layer does not change the globe, terrain, wells, utilities, weather, celestial objects or other overlays.
- Selecting an icon opens the original creator-hosted interactive 3D viewer: Sketchfab for the previous CC Attribution scans and the new China/Japan public photo-mesh embeds, or Matterport for Ohio. Each card retains creator, rights/access status and capture method. New China/Japan cards intentionally do not contain outbound clickable site links.
- Site markers carry explicit location precision. A marker can be a site/region anchor when a scan creator has not published exact chamber coordinates.
- Meshes are not downloaded, cached, georegistered or redistributed. The viewer-first integration does not claim that a model is a metrically aligned underground mesh tile. The Matterport tour is not CC-licensed, so it is only embedded, not copied.

**African rock-art cave 3D addition (v14):** Elands Bay Cave is a genuine coastal rock shelter at Baboon Point in the Western Cape, South Africa, long used by people and known for San/Khoe rock art with eland depictions and handprints. The Rock Art Portal published the textured, interactive 3D original at https://sketchfab.com/3d-models/elands-bay-cave-d0c88d0853844a8e9a1de22a342326cb . The model has around 408,500 polygon triangles and used roughly 250 DSLR photographs plus 1,500 aerial drone photographs and three terrestrial laser scans, processed with RealityCapture/Blender/MeshLab; this is a solid photo-textured, *mixed-source* surface mesh, **not** a raw point cloud and not exclusively camera-only photogrammetry. The source is marked NoAI, and no transferable CC reuse license was displayed; BridgePoint embeds only the existing creator-hosted Sketchfab viewer inside its card, does not copy the 3D model, and does not use the model for generative AI. The icon uses the OpenStreetMap cave entrance node 10614878708 (lon 18.31766, lat -32.31779) reported at https://mapcarta.com/N10614878708 . South African History Online independently describes the archaeological history at https://sahistory.org.za/place/elands-bay-cave . The original artist/research-portal attribution stays visible, and there is no outbound site link in the new card. All 18 previous models, the persistent marker design, the Ohio embedded-viewer fix and all unrelated globe features remain unchanged.

**Antarctica solid 3D cave model (v13):** Add one genuine Antarctic coastal rock cave archaeological site, Lima-Lima Cave, at Lair Point, Byers Peninsula, Livingston Island. It is a former nineteenth-century sealer/whaler shelter documented in field research. Sketchfab original by LEACH/UFMG and White Landscapes Project (Alex Martire): https://sketchfab.com/3d-models/lima-lima-cave-post-excavation-899e6c8016954dab825dffb07d583fb9 . The 2M-triangle 3D polygon surface model was generated using Leica P20 terrestrial laser scanning data and meshed in Metashape 1.8.3. **Important: this is not a photo-based photogrammetry model**; it is a genuine solid cave surface mesh rather than the raw LiDAR point cloud. We did not find a publicly embeddable photographic scan of an Antarctic cave, so this real polygon model was selected over presenting an invented ice cave or a point cloud. No downloadable rights/license was displayed; we embed the original, creator-hosted viewer only and do not copy or redistribute source mesh. The exact documented archaeological site anchor is from Antarctic Treaty Secretariat Measure 10 (2022), Byers Peninsula (ASPA 126) Management Plan, Table 1, `62°36′55.62″S, 61°02′13.08″W`, decimal lat -62.61545, lon -61.0369667: https://documents.ats.aq/recatt/att720_e.pdf . This protected site is displayed for virtual exploration only, not a visitor destination. The prior sixteen sites, seventeen models, large persistent icon styling, in-BridgePoint sandboxed viewer, Ohio fix, and all other globe features are unchanged.

- Other university / agency cave-survey collections remain candidates until each individual model's download status, creator, license and location precision are checked.

## Sketchfab API / file handling constraint

The current integration uses the hosted Sketchfab viewer. Sketchfab's Download API requires end-user authentication/OAuth unless a separate agreement permits application-side downloads. Current API documentation lists glTF, GLB and USDZ download options; do not assume OBJ/PLY are available through this API. Do not cache temporary download URLs or copy model files without applicable rights and authorization.
