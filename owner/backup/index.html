What the full archive contains

Database
Portable pg_dump custom archive + schema/data/roles/migration-history SQL.
Storage
Bucket contents copied through Supabase's S3-compatible endpoint when credentials are supplied.
Source code
Mirror clones of BridgePoint source and live repositories.
Integrity
SHA-256 checksum manifest + pg_restore catalog verification.
Secrets
Live secrets are deliberately excluded. The archive includes a restore checklist so credentials can be re-created safely instead of being copied into a portable archive.
A full production export is large. Run it from the Windows PC with enough free disk space. The Owner Center only marks export/verify/restore as successful after the PC reports actual completion.
