1 · Generate enrollment

Generate this only when you are at the new PC and ready to run the installer. The code is single-use and expires quickly.

2 · Run the canonical installer

After the private bridgepoint-live repository is on the new desktop, open PowerShell as Administrator in ops\local-node and run:

Set-ExecutionPolicy -Scope Process Bypass .\install.ps1 -DataRoot "C:\BridgePointData"

The installer requires at least 600 GB free on the hot-data drive, keeps Ollama on 127.0.0.1, protects the node token with Windows DPAPI, and installs one Windows Scheduled Task named BridgePoint Autonomous Node. Do not install the older fallback scheduled task at the same time.

3 · Automatic handoff

After the heartbeat turns ONLINE at v938, the backend can unlock governed local reasoning and the already-authorized export queue. Export remains resumable and cannot bypass storage/integrity gates. OneDrive remains cold archive only; the live DuckDB stays on the SSD.
