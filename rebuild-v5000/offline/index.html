Source and data limits

The global base package is generalized to zoom 0–6. Detailed country boundaries add outline fidelity, but they do not create building or parcel geometry where no suitable source exists.

Cached hazards and emergency information can become stale. BridgePoint never treats an old snapshot as live, nor treats general hazard exposure as confirmed property damage.
