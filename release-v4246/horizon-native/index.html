This page exposes the UE5.8 systems now committed to BridgePoint Horizon. The immediately playable web preview remains a Three.js/WebGL client; Unreal Engine 5.8 does not publish directly to browsers. A true interactive UE view requires a packaged native build running on a GPU host through Pixel Streaming.

Current publish state: the native source is public in the Horizon repository and production site manifest. It is not being represented here as a compiled Unreal executable until an actual UE5.8 packaging + GPU streaming runner is available and verified.
