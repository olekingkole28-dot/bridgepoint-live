# BridgePoint Free Property & Claim Utilities

Small, no-login utilities for contractors, restoration teams, public adjusters, property managers, and property-intelligence workflows.

These utilities are intentionally simple and transparent. They do **not** determine that a property was damaged, that a claim is valid, or that coverage applies. They help organize inputs before deeper review.

## Included tools

### Claim evidence preflight
`claim_evidence_preflight.py` checks a plain-text claim/property note for common evidence categories you may want to gather before review: property identity, event timing, weather context, photos/media, permit/code context, scope/estimate references, and source/provenance notes.

### Coordinate formatter
`coordinate_formatter.py` validates and normalizes latitude/longitude pairs into common formats used in mapping/property workflows.
