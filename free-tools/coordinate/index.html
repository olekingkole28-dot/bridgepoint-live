Coordinate Formatter

Validate a latitude/longitude pair and convert it into common property and geospatial formats. Everything runs in this browser; the values you enter are not sent anywhere.

What it outputs

  • Decimal latitude, longitude
  • CSV pair
  • GeoJSON coordinate order: longitude, latitude
  • Maps-query pair

This utility only validates coordinate ranges and reformats values. It does not geocode an address or verify property identity.
